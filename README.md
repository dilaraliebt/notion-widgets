## 📅 Kalender

Ein ruhiger, cleaner Monatskalender auf Deutsch – perfekt für deine Notion-Seite.

**Features:**
- Woche beginnt mit Montag
- Heutiges Datum wird hervorgehoben
- Farben anpassbar per URL-Parameter
- Navigation zwischen den Monaten

**So bindest du ihn in Notion ein:**
1. Öffne deine Notion-Seite
2. Tippe `/embed`
3. Füge die URL ein und drücke Enter
4. Fertig – dein Kalender erscheint! 🎉
